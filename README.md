На сайте реализован локальный ИИ-консультант, работающий в браузере. Лёгкий и быстрый, работает даже на смартфонах. 
Цена домена promisteel-in-belarus по следующей формуле: 12+5*N долларов США, где 12 — цена на 2026 год в долларах США, N — количество лет после 2026 года на дату продажи домена.
Я использовал наименование promisteel так как сайт разрабатывался на безвозмездной основе по устному согласованию "для портфолио". При этом домен арендовывал я, вложил в его свои деньги.
Этот сайт ни коим образом не свидетельствует о текущей деятельности компании в Беларуси, это лишь пробная работа для набора опыта студента магистратуры😁 для резюме и портфолио.
